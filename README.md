# Right Track

План роста дохода школы Right Track: презентация, экспресс-отчёт и концепт новой версии сайта.

| Что | Адрес |
|---|---|
| Презентация, 17 слайдов | [konkovdv.github.io/rightrack](https://konkovdv.github.io/rightrack/) |
| Экспресс-отчёт | [/2_demo_otchet.html](https://konkovdv.github.io/rightrack/2_demo_otchet.html) |
| Тот же отчёт, PDF | [/2_demo_otchet.pdf](https://konkovdv.github.io/rightrack/2_demo_otchet.pdf) |
| Концепт сайта, 6 страниц | [/site_v2/](https://konkovdv.github.io/rightrack/site_v2/) |

## Как смотреть

- **Презентация.** Стрелки, `PageUp`/`PageDown`, `Home`, `End` листают слайды, `F` включает весь экран. Справа колея: точка на каждый слайд. Адрес с номером ведёт сразу на нужный слайд: `…/rightrack/#14`.
- **Калькулятор на пятом слайде** считает на цифрах, которые вписаны в жёлтые поля. От них же пересчитывается слайд «Экономика решения». Кнопка «Ссылка на этот расчёт» копирует адрес, по которому расчёт откроется с теми же цифрами.
- **Финал.** Формат чекапа и понедельник старта дают срок готовности по рабочим дням. «Скопировать итог» собирает текст для мессенджера.
- **Отчёт.** Пример карточки открыт на экране, кнопка или `E` его прячет. В печать и PDF пример не попадает.
- **Сайт.** `N` включает пояснения к блокам. Форма заявки в концепте данные не передаёт и показывает настоящий контакт школы для записи.

Презентация и отчёт работают без интернета: шрифты встроены в файл, иллюстрации лежат рядом в папке `art/`.

## Устройство

```
index.html            презентация
2_demo_otchet.html    экспресс-отчёт (+ PDF)
site_v2/              концепт сайта: 6 страниц, общий слой в assets/js/site.js
art/                  иллюстрации
og/                   картинки превью для мессенджеров
tests/                проверки Playwright
tools/                сборка PDF
```

Настройки сайта (контакты, даты встреч, окно цены предзаписи) лежат в одном месте: `site_v2/assets/js/site.js`, блоки `CFG` и `GROUP`. Прошедшие даты и закрывшиеся окна скрываются сами.

Цифры презентации живут в одном скрипте в конце `index.html`: `D` — выручка продуктов по сценариям, `M` — потоки, люди и чеки калькулятора, `Z` — оценки восьми зон.

## Проверки и сборка

```bash
npm ci
```

```bash
npm run check
```

```bash
npm run pdf
```

`check` проверяет каждую страницу: ошибки консоли и битые ссылки, WCAG 2.2 AA через axe, вёрстку на ширинах от 320 до 2560 px, калькулятор на случайных данных против эталонной модели, сроки и таймеры на фиктивных часах, формы на опасных строках, печать отчёта ровно в четыре листа. `pdf` пересобирает `2_demo_otchet.pdf` из страницы отчёта.

## Публикация

Workflow `.github/workflows/pages.yml` проверяет каждый push и из `main` публикует сайт на GitHub Pages.
